# Biomarker threshold reference

Quick reference for the clinical thresholds used in trend interpretation.

| Biomarker | Unit | Threshold | Meaning |
|---|---|---|---|
| HbA1c | % | 5.7 | Prediabetes threshold — crossing flags the reading |
| HbA1c | % | 6.5 | Diabetes range |
| LDL | mg/dL | 160 | "High" — crossing flags the reading |
| HDL | mg/dL | 40 | "Low" — protective effect lost below this |

## Notes

- Threshold crossings are detected only when a reading **moves from below to at/above** the threshold between consecutive readings.
- The clinical *significance* of a crossing depends on the patient's genetic flags.
